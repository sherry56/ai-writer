# 写作 Skill

本文件是所有 AI 模型生成大纲 / 初稿 / 修改时**必须遵守的写作规则**，优先级高于内容模板（tutorial / product_review 等）。
直接编辑这个文件即可调整规则,无需重启服务(每次生成都会重新读取)。

## 结构骨架(顺序固定)

1. **开篇引入(钩子)** — 用读者第一反应的疑问 / 误区 / 痛点开场,3-5 句之内进入正题。开篇必须含具体场景或对话感,不要抽象判断。
2. **过渡一句话** — 用「这篇就讲一遍 / 比如 / 我们一起做」之类的过渡句把读者带入正文。
3. **主体(3-6 段,每段一个二级标题)** — 按"准备 → 操作 → 进阶 → 注意"的认知顺序展开。
   - 每段开头先用 1 句话点明本节解决什么问题。
   - 关键步骤用列表 / 表格 / 短代码块呈现,避免长段落。
   - 出现新名词立刻给一句话解释,不留专业术语门槛。
4. **总结收束(单独一段,三级标题「小结」或「总结」)** — 回收开头痛点,给一句"现在你可以…"的结论,不堆口号。

## 标题与排版(硬性要求,违反直接当 bug)

- 一级标题(`#`)**只用一个**,就是文章总标题,且就是给定的选题标题,**不要改写**。
- 文章主体的每个段落必须用 **二级标题(`##`)**,**不准用 `###` 直接作为主体段(违反例子:`### 高转发内容...`)**。
- 二级标题强制格式:`## 中文序数、简短主旨`,例如:
  - ✅ `## 一、找准身份认同`
  - ✅ `## 二、设计转发钩子`
  - ❌ `### 高转发内容,几乎都在解决读者的"身份管理"问题`(太长 + 用了 ### + 没序数)
- 二级标题**含序号总共最长 12 个汉字**,超出立刻砍短。
- 三级标题(`###`)只在「二级标题之下需要再细分子步骤」时才允许出现,且同样最长 12 字。
- 表格用于「对比 / 速查」,代码块用于「命令 / 示例」,引用块(`> `)用于「提示 / 警告」。
- **每个二级标题(`##`)前必须加一行分割线 `---`**(第一个 `##` 也要;一级标题之后留空行再 `---` 再空行再 `##`),用来收束上一节、起一节。
- 长链接写成 markdown 链接形式 `[文字](url)`,不要裸 URL。

## 语感与用词

- 第二人称「你」为主,避免「我们 / 大家 / 咱们」之类含糊主语。
- 短句优先,行末用换行不用句号堆砌。
- 把抽象动词改成具体动作:"实现配置" → "在终端输入 xxx";"赋能" → 直接写做什么。
- 不准营销腔(赋能 / 颠覆 / 重磅 / 小白也能 5 分钟搞定)。
- 出现具体数字、产品名、命令时不要打折扣;不知道就标 [待核实]。
